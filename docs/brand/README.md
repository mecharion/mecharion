# Logo

`mecharion-logo.svg` 是可编辑的源文件（1024×1024，纯几何路径，无外部字体/滤镜依赖）；`mecharion-logo-512.png` 是导出的位图，供不方便用 SVG 的场合（社交预览图之类）使用。

生成/调整这份 logo 的工具（Go 标准库实现，零第三方依赖）在设计者本地保留，不在这个仓库里——这里只保存最终产物本身。

## 寓意

整个图形首先是一个清晰的抽象字母 M，直接对应 Mecharion，即使脱离文字也具备品牌识别能力。

三种蓝色结构分别映射项目的三个核心对象：亮蓝右侧代表被管理的节点、集群以及向外扩展的执行能力；青色下方的双向折线代表应用生命周期：部署、收敛、更新、替换与持续调谐。两个负形三角共同指向中心，表达"应用与节点状态汇聚到控制核心"，随后控制指令再向两侧分发——这与声明期望状态、协调节点、执行生命周期操作的工作方式高度吻合。

中心的琥珀色圆点同时具有三层含义：机械结构中的关节和轴心（对应 mechanism）；调度、协调和状态收敛的控制节点；机械生命体的"心脏"，保留了 Arion 不知疲倦、持续奔跑的生命意象。

## 用在哪

| 位置 | 文件 |
|---|---|
| Web UI favicon | `webui/public/favicon.svg` + `apple-touch-icon.png`（这两份是从这里复制过去的，不是引用） |
| 官网 favicon 与首页图标 | `mecharion/website` 仓库自己的 `docs/public/` 下（同样是复制，不是跨仓引用——两个仓库各自独立部署，不应该有运行期依赖） |
| README 顶部 | 直接引用本目录下的 `mecharion-logo.svg` |

**改这份 logo 时，三处复制都要手工同步**——没有自动化管线把这里的改动推到 `webui/`/`website`，理由与运维手册（`docs/ops/`）跨仓同步的取舍一样：改动频率低，人工同步的成本低于维护一条同步流水线。
