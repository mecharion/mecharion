# ADR-0033: mechlet 持有本地期望状态与密钥副本

- **状态**：已接受
- **日期**：2026-08-05
- **相关**：[ADR-0001](0001-agent-based.md)、[ADR-0030](0030-secret-storage-and-delivery.md)、[ADR-0002](0002-mechlet-as-sole-engine.md)

## 背景

到 M4 为止，mechlet 只在 mechd 推送期望状态时调和一次。M5 要加周期性调和
——那是[常驻 Agent 相对 Ansible 的核心价值](0001-agent-based.md)：有人手工
改了配置、手工停了服务，只有周期性重读才能发现。

周期调和需要一份**本地的期望状态**。规格本身落盘没有障碍，麻烦在密钥。

[ADR-0030](0030-secret-storage-and-delivery.md) 定的是：规格里存哨兵
`@@m7n:secret:<id>@@`，明文随 gRPC 消息下发，**在写盘的最后一刻**换进去，
用完即弃、绝不落盘。于是：

> **mechlet 重启后，带密钥的实例在下一次推送之前无法调和。**

`spec.ResolveSecrets` 在缺明文时是硬错误，错误信息里那句「重连后会全量
重推」正是这个设计的体现。而「重启后自己恢复」恰恰是常驻 Agent 最该做到
的事——尤其在与 mechd 断连时，那正是最需要它的时候。

## 候选

| 做法 | 重启后能自愈的实例 | 泄漏面 |
|---|---|---|
| **A** 规格只留在内存 | 无 | 不变 |
| **B** 规格落盘（哨兵），明文只在内存 | 只有不带密钥的 | 不变 |
| **C** 规格落盘 + 明文进 mechlet 本地信封加密库 | 全部 | **扩大**（见下） |

## 决策

**采用 C。** mechlet 落盘两样东西：

```
<data-dir>/desired/<component>-<role>.json   已解析规格（含哨兵，无明文）
<data-dir>/vault/                            DEK 加密后的密钥值
<data-dir>/kek                               KEK，0600，root 独占
```

信封加密的机制与 mechd 侧完全一致（[ADR-0030](0030-secret-storage-and-delivery.md)）：
KEK 在文件里、DEK 在库里、AES-256-GCM 且 AAD 绑定条目身份。
**复用 `internal/vault`，不新写一套**——两套信封实现意味着两套边界条件，
而其中一套的测试覆盖必然更薄。

同样保留「默认开启、可关」：关掉时是明文 + 0600，与 mechd 侧的取舍一致。

## 后果

### 收益

- **重启后立刻恢复周期调和**，不区分实例带不带密钥。行为可预测——
  这是选 C 而非 B 的直接原因：B 让「重启后会不会自愈」取决于这个组件
  恰好有没有 `type: secret` 参数，而那不是用户脑子里会有的分类。
- **断连期间也自愈。** 断连 + 重启是最坏的组合，也正是 A 和 B 都失效
  而 Agent 最该顶用的时候。
- mechd 不必为了「让节点重新能干活」而周期性重推全量密钥。

### 代价（明确接受）

- **节点上多了一份可解密的凭据副本，且 KEK 就在同一台机器上。**
  这把「这台节点被拿下」的后果从**拿到当前落盘的配置**扩大到
  **拿到该节点上全部组件的凭据明文**。

  这是一个真实的、永久的、全局的扩大，不是理论风险。接受它的理由是：
  能读到 `<data-dir>` 的攻击者已经是 root 或等价身份，而那样的攻击者
  本来就能读到渲染出的配置文件（里面有同样的口令）、能 attach 到跑着的
  进程、能改 unit 文件。**KEK 与 DEK 同机保护的边界，本就只有「磁盘被
  离线取走」这一种情形**——那种情形下它仍然有效。

  它不能防的是「在线的 root」。这一点必须写在文档里，而不是让人以为
  信封加密提供了它并不提供的保护。

- 密钥轮换多了一处要同步的地方：mechd 换了值，mechlet 侧的副本要跟着换。
  推送时覆盖即可，但**删除**（组件被移除）时必须一并清掉，否则会留下
  没有主人的凭据。

- mechlet 的备份/迁移语义变了：`<data-dir>` 现在含凭据，不能随手拷。

### 不接受的替代

- **不做「只缓存哈希、用时向 mechd 要」**：那把自愈重新绑回了连通性，
  等于 B 换个说法。
- **不用系统 keyring / TPM**：v1 的目标环境包括没有这些东西的机器，
  而一个「有的机器上安全、有的机器上不安全」的方案比一个到处一致的更糟。
- **不用 systemd 的 `LoadCredentialEncrypted`**：已在项目层面排除。
